# Oracle Functions — Funciones avanzadas
**Nelson** · Fundador y CDO · [Simov Labs](https://simov.io)
---

Este proyecto está en construcción para **documentar** y ofrecer **ejemplos básicos** del uso de funciones y cláusulas avanzadas en Oracle SQL. La idea es tener una referencia clara y consultas listas para probar en esquemas como **OE (Order Entry)**.

A medida que avancemos, iremos añadiendo más temas y ejemplos.
